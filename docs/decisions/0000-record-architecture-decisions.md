# 0000. Record architecture decisions

- Status: Accepted
- Date: 2026-11-10

## Context
Decisions that are expensive to reverse get lost in chat and commit history.

## Decision
Record each such decision as a numbered ADR in `docs/decisions/` using the template in the `software-architecture` skill. Statuses: Proposed, Accepted, Superseded by NNNN, Deprecated. Notion's Decisions database indexes them; the text lives here.

## Consequences
Reviewers can ask "which ADR covers this?"; changing a decision means writing a new ADR, not editing an accepted one.
